# Monthly Budget Contributions

A small React calculator for two people planning a monthly budget.

Enter each person's income, rent, other bills, and a savings goal. The app subtracts those shared amounts from total income, then divides the remainder between the two accounts in proportion to their incomes.

## Run locally

1. Run `npm install`.
2. Run `npm start`.

The calculator runs in your browser and does not save entries. Displayed amounts are rounded to cents.
